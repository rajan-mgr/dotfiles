# Hyprland Dotfiles

My Hyprland configuration files for Arch-based Linux distributions.

## Installation

### 1. Install Git

```bash
sudo pacman -S git
```

### 2. Clone the repository

```bash
git clone git@github.com:rajan-mgr/dotfiles.git ~/dotfiles
```

### 3. Run the installer

```bash
cd ~/dotfiles
chmod +x install.sh
./install.sh
```

The script installs the required packages and configures the dotfiles automatically.

### Supported

* Arch Linux
* CachyOS
* Garuda Linux
* EndeavourOS
